# CleanTrack PH

A full-stack civic technology platform that empowers Filipino residents to report 
illegal dumping, road waste, and sewer blockages in real time — helping LGU officials 
take faster action to prevent flooding.

## Features

- 📍 One-tap waste reporting with automatic GPS location capture
- 📸 Photo upload support for evidence documentation
- 🗺️ Live map showing all reports across Pampanga
- 🏛️ LGU admin dashboard with status management (pending → in progress → resolved)
- 🔐 Secure admin authentication via Supabase Auth
- 📊 Real-time report statistics and filtering by type and status

## Tech Stack

- **Frontend:** Next.js 16, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Auth, Storage)
- **Maps:** Leaflet.js + OpenStreetMap
- **Deployment:** Vercel

## The Problem

The Philippines loses billions of pesos annually to flooding caused by clogged 
drainage systems. Illegal dumping is the primary cause — but reports go untracked 
and officials have no centralized system to act on them. CleanTrack PH bridges 
that gap.
